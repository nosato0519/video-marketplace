# Integration map

The service can be extended beyond source-code tooling by connecting operational services around the same event model.

Potential non-programming integrations include:

- Email: security alerts, account notices, purchase receipts
- Chat/notifications: admin alerts and operational incidents
- Analytics: product usage and conversion measurement
- Payments: purchase and payout status events
- Storage/CDN: media storage and delivery lifecycle
- Monitoring: uptime, errors, and security signals
- Customer support: reports, tickets, and moderation workflows
- Accounting: sales, fees, refunds, and payout records

The current project should add integrations only when they solve a concrete operational need. Credentials and secrets must remain outside source control.
