# Build scope

This document keeps the current project focused on the video marketplace.

## In scope

- Buyer experience
- Seller experience
- Product catalog and video publishing
- Checkout and transaction lifecycle
- Access control and video delivery
- Refunds and seller settlement
- Moderation, reporting, evidence handling, and audit logs
- Admin operations
- Security regression testing
- Monitoring, backups, and production readiness
- Revenue measurement and optimization

## Out of scope for the current build

Unrelated future products, games, and standalone automated video-editing products are intentionally deferred until the marketplace is production-ready.

## Rule

When a new idea appears during development, record it separately if useful, but do not mix it into the implementation plan unless it directly supports the marketplace.
