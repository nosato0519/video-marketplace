あなたはプロのWebデザイナー兼フルスタックエンジニアです。

これから動画販売マーケットプレイスの「完成品レベルのデモサイト」を制作してください。

重要：

これは単なる機能確認用のテスト画面ではありません。

実際に販売できるWebサービスを購入希望者に見せるための「商品デモサイト」です。

そのため、最初から以下を最優先してください。

【最重要】

1. 一般的な動画販売サービス・デジタルコンテンツ販売サイトとして自然に見えること

2. 初めて見た人が「これは完成したサービスだ」と感じること

3. デザイン、レイアウト、余白、フォント、色、画像、カード、ボタン、導線をプロ品質にすること

4. PC・スマートフォンの両方で完成度の高いUIにすること

5. テスト用画面・管理画面っぽい無機質なデザインにしないこと

6. 「機能がある」だけではなく、「実際に使いたくなる」デザインにすること

7. 最初から完成形を想定して作り、後から簡単な見た目を大幅改修する前提にしないこと

【デザイン】

以下を意識する。

・プロのSaaS/マーケットプレイス品質

・高級感

・余白を十分に取る

・視線誘導

・統一されたデザインシステム

・自然なカードUI

・魅力的な画像

・分かりやすいCTA

・レスポンシブ

・ホバー・トランジション

・空状態も綺麗にする

・エラー表示も自然にする

・ローディング状態も用意する

【重要な禁止事項】

・簡素なテストページにしない

・ボタンを大量に並べるだけにしない

・管理画面だけを作って完成扱いにしない

・機能確認用UIを完成品UIとして扱わない

・「後でデザインを直す」前提で作らない

・placeholderだらけにしない

・Lorem ipsumを使わない

・意味のないダミー要素を大量に置かない

【デモとして必要な動作】

見た目だけのモックではなく、実際にクリックして確認できるようにする。

最低限、

トップページ

→ 商品一覧

→ 商品詳細

→ 購入

→ マイライブラリ

→ 視聴

→ ダウンロード

まで一連の操作ができること。

さらに、

Buyer

Seller

Admin

の3つのロールを切り替えて、それぞれの主要機能を確認できること。

決済はデモではシミュレーションで構わないが、

「デモ決済」と明確に分かるようにする。

【最終条件】

制作途中の状態を完成扱いにしない。

完成前に、

・トップページ

・商品一覧

・商品詳細

・購入

・マイライブラリ

・視聴

・ダウンロード

・Seller

・Admin

・PC表示

・スマホ表示

をすべて確認する。

見た目についても、

「機能は動くがサイトとして安っぽい」

という状態を完成と判断しない。

最終的には、

「このデモを見せれば、このWebシステムを販売できる」

と思えるレベルまで仕上げる。

不足している部分は自分で判断して補完し、

必要なコード・HTML・CSS・JavaScript・バックエンドも実装してください。

**さらに重要なのは、この一文。**

**「機能確認用のデモではなく、完成した商用Webサービスを購入希望者に見せるための販売用ショーケースとして作る」**
