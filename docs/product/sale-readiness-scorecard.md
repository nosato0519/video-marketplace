# Sale-readiness scorecard

The marketplace should be evaluated as a sellable software product, not only as a working demo.

## Required before sale

- Core buyer and seller flows work end-to-end
- Product detail and catalog data are connected to the database
- Authentication and authorization are enforced
- Payment and refund lifecycle is implemented and tested
- Video access is protected
- Moderation and reporting workflows are operational
- Security controls and audit trails are tested
- Admin operations are documented
- Production configuration is separated from development configuration
- Setup, deployment, backup, and recovery instructions are complete
- Known limitations and third-party dependencies are documented
- A clean demo environment can be provided to a prospective buyer

## Evaluation principle

A buyer should be able to understand what the product does, verify the important flows, estimate operating costs, and deploy it without depending on undocumented knowledge.
