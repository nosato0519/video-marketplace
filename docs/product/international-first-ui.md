# International-first UI

The first sale target is international buyers. The product UI should therefore use an international-first visual and information hierarchy.

## Design direction

- Clean, modern marketplace presentation
- Strong visual product cards and previews
- Clear pricing and primary calls to action
- Generous spacing and readable typography
- Trust signals near purchase actions
- Mobile-first responsive behavior
- English as the initial product language
- Currency and locale kept configurable for future expansion

## Productization rule

Regional presentation must be configurable rather than hard-coded. The first implementation is optimized for international sale, while preserving a path to Japanese localization later.
