# Revenue metrics

Track the marketplace with measurable operating metrics rather than relying on revenue assumptions.

## Core metrics

- Registered buyers
- Active buyers
- Registered sellers
- Active sellers
- Published products
- Product page conversion rate
- Checkout conversion rate
- Gross merchandise value (GMV)
- Platform revenue
- Seller payout total
- Refund rate
- Chargeback rate
- Repeat purchase rate
- Customer support volume

## First revenue milestone

The first target is a complete real transaction lifecycle in a controlled environment: seller publishes a product, buyer completes checkout, access is granted, the transaction is recorded, and a refund can be processed safely.
