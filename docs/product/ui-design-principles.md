# UI design principles

The initial marketplace is international-first, but it must not look generic. The visual system should make usability obvious while remaining distinctive, polished, and simple.

## Principles

- International visual language without copying common marketplace templates
- One clear primary action per screen
- Navigation that can be understood immediately without instructions
- Strong visual hierarchy: product, value, price, trust, action
- Minimal clutter and restrained use of color
- Consistent spacing, typography, buttons, cards, and states
- Product previews should communicate what is being purchased quickly
- Trust information should appear at decision points rather than hidden in footers
- Responsive behavior must preserve hierarchy on small screens
- Accessibility and readable contrast are part of the visual design

## Differentiation goal

The product should be recognizable from its visual rhythm and interaction patterns while remaining easy for a first-time international user to understand within seconds.
