# 購入者ガイド

## このシステムについて

本サービスは、動画を検索・比較・購入し、購入後にマイライブラリから視聴・ダウンロードできる動画マーケットプレイスです。

## 購入から利用まで

1. 商品を検索します。
2. 商品詳細でタイトル、説明、価格、プレビュー、販売条件を確認します。
3. アカウントへログインまたは登録します。
4. チェックアウトで注文内容と決済情報を確認します。
5. 決済完了後、購入済み動画がマイライブラリに表示されます。
6. マイライブラリから視聴します。
7. ダウンロード可能な商品は「ダウンロード」から保存できます。

## ダウンロードについて

ダウンロードは購入権限が有効な本人だけが利用できます。動画ファイルは公開URLとして配置せず、サーバー側で購入権限を確認してから配信します。大容量ファイルや通信中断を考慮してRangeリクエストにも対応します。

## 困ったとき

購入した商品が表示されない場合は、まず購入時と同じアカウントでログインしていることを確認してください。決済済みなのに利用できない場合は、注文IDを控えて運営サポートへ連絡してください。

## 利用前に確認すること

購入前に商品説明、価格、利用条件、返金条件、ダウンロード可否を確認してください。販売者ごとの権利・利用条件が設定されている場合は、それを優先して確認してください。
