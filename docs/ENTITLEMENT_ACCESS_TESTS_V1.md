# Entitlement & Protected Media Tests V1

- A pending order cannot create an entitlement.
- A failed/cancelled order cannot create an entitlement.
- A verified paid order creates an entitlement for the server-side buyer only.
- A product mismatch is rejected.
- An active entitlement is required for buyer media access.
- A revoked entitlement cannot access media.
- An unpublished product cannot be streamed through the buyer endpoint.
- A non-ready media asset cannot be streamed.
- A buyer cannot use another user's entitlement identifier to gain access.
- A seller cannot gain buyer entitlement merely by owning the product.
