# VIDEO MARKETPLACE — 5-Minute Sales Demo Script

## Purpose

Use this script to demonstrate the system quickly and consistently to a prospective buyer. The goal is to show that the product is a complete video marketplace foundation with buyer, creator, and administrator experiences—not simply a collection of static pages.

## 0:00–0:40 — Homepage

Show the premium homepage first.

Key message:

> 「動画販売に必要なすべてを、ひとつのシステムに。」

Explain that the showcase is designed as a complete video marketplace foundation and can be adapted to different video-selling business models.

Point out:

- Premium storefront presentation
- System/features overview
- Operable as a base system and freely customizable
- Buyer, creator, and administrator experiences

Do not spend time changing the homepage during the sales demo. It is the reference visual direction.

## 0:40–1:30 — Discovery and product detail

Open the video list/search experience.

Demonstrate:

1. Search
2. Category/filter controls
3. Sorting
4. Video card selection
5. Product detail
6. Preview interaction

Key message:

> 「探すところから購入判断まで、一連の導線を用意しています。」

Emphasize that the same foundation can be adapted to courses, tutorials, fitness, creator content, premium libraries, stock/event video, and other specialty video businesses.

## 1:30–2:20 — Checkout to library

Open checkout from the product detail page.

Demonstrate:

- Order summary
- Customer information validation
- Required-field validation
- Demo purchase completion
- Automatic transition to the purchased library

Key message:

> 「購入後のユーザー体験まで、最初から最後まで設計されています。」

Important boundary:

- This showcase uses simulated checkout.
- Do not describe the demo as processing a real payment.

## 2:20–3:00 — Library and watch

From the library, open purchased content and enter the watch page.

Demonstrate:

- Purchased-content presentation
- Watch/player experience
- Player controls
- Return to library
- Demo-safe media controls

Key message:

> 「購入して終わりではなく、購入後の視聴までつながっています。」

## 3:00–4:00 — Creator Studio

Open Creator Studio.

Show the operational scope:

- Sales overview
- Product management
- Media upload/lifecycle
- Moderation/publishing
- Earnings
- Payout area

Key message:

> 「販売者側の運営画面も、購入者側とは別に用意されています。」

Clarify that payout controls in the showcase are demo-safe and do not perform a real financial transfer.

## 4:00–4:40 — Admin

Open the administrator area.

Show:

- Dashboard
- Seller/creator review
- Product moderation
- Users
- Sales
- Payout oversight
- Security area

Key message:

> 「マーケットプレイスを運営する側の管理機能まで含めた構成です。」

Demonstrate review actions only as safe demo interactions.

## 4:40–5:00 — Close

Finish with the customization and production message.

Suggested closing:

> 「この状態をベースに、ロゴ・カラー・カテゴリー・料金体系・トップページ・会員機能などをお客様の事業に合わせて変更できます。デモでは安全のため決済や本番メディア配信はシミュレーションにしていますが、本番環境では決済・認証・ストレージなどをお客様の環境に合わせて組み込めます。」

## Demo rules

- Never claim the showcase demo is a live production payment service.
- Never enter real customer credentials or payment information.
- Never present demo media controls as real protected-media delivery.
- Keep the homepage visually unchanged unless a customer-specific redesign has been agreed.
- Demonstrate the buyer journey first, then creator and admin operations.
- Use the production requirements in `SALES_PACKAGE.md` and `COMMERCIAL_PACKAGE.md` when discussing actual deployment.

## Recommended sales order

`Homepage → Video List → Product Detail → Checkout → Library → Watch → Creator Studio → Admin → Customization/Production`

This order keeps the explanation centered on the complete business flow and makes the system scope easy to understand within five minutes.
