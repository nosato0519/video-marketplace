# Visual Acceptance Checklist

## Purpose

This checklist is the gate for the sales-demo visual pass. It separates verified behavior from visual items that require rendered-browser inspection.

## Reference direction

The current demo is intentionally a close visual study of Vimeo OTT's public information architecture: restrained navigation, oversized editorial hero, black/white sections, metric band, feature sections, strong CTA and structured footer. Vimeo branding, proprietary copy and imagery are not copied.

## No-waste rule

Do not change CSS or demo structure solely because an item is unchecked. Only make a code change after a concrete rendered defect or interaction failure is observed. Do not mark final acceptance without rendered-browser evidence.
